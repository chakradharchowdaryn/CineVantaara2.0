# 🎬 CineVantaara — Where Stories Meet Talent

CineVantaara is a next-generation cinema collaboration and talent ecosystem platform designed for filmmakers, actors, directors, screenwriters, and cinema enthusiasts.

## 🚀 Features
- **12 Specialized Film Workbenches**: Director, Screenwriter, Actor, Cinematographer, Music Director, Producer, Editor, and more.
- **6-Theme Dynamic Emblem Engine**: Real-time 3D metallic and neon shader skins.
- **Citadel Autonomic Security**: 6-digit OTP verification with Google Cloud Gmail API & Brevo relays.
- **24/7 Cloud Architecture**: Designed for instant, zero-maintenance deployment on Vercel.
- **Mobile PWA & APK**: Fully responsive with standalone offline capabilities.

## 🛠️ Tech Stack
- **Framework**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS, Lucide Icons, Glassmorphic UI
- **Serverless**: Vercel Serverless Edge Functions (`/api`)
- **Email Engine**: Google Apps Script Relay + Brevo REST API

## ⚡ Deployment on Vercel
1. Import this repository into Vercel.
2. Vercel automatically detects **Vite**.
3. Click **Deploy** — your live cinema platform is ready in 30 seconds!
